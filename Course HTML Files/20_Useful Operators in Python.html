The enumerate Function

The enumerate Function with 1 parameter

string = "Hello"
for item in enumerate(string):
    print(item)  # Prints index and character
(0, 'H')
(1, 'e')
(2, 'l')
(3, 'l')
(4, 'o')

The enumerate Function with 2 parameters

listy1 = ['a','b','c','d','e']

The zip Function

The zip Function on even length datatypes

list1 = [1, 2, 3, 4]
set1 = {'a', 'b', 'c', 'd'}
dict1 = {0: 'apple', 1: 'banana', 2: 'guava', 3: 'pear'}

for item in zip(list1, set1, dict1.items()):
    print(item)  # Combines one item from each collection
(1, 'a', (0, 'apple'))
(2, 'd', (1, 'banana'))
(3, 'c', (2, 'guava'))
(4, 'b', (3, 'pear'))

The zip Function on un-even length datatypes

list1 = [1, 2, 3, 4]
set1 = {'a', 'b', 'c', 'd', 'e'}  # Longer
dict1 = {0: 'apple', 1: 'banana', 2: 'guava'}  # Shorter

for item in zip(list1, set1, dict1.items()):
    print(item)  # Stops at the shortest iterable
(1, 'a', (0, 'apple'))
(2, 'e', (1, 'banana'))
(3, 'd', (2, 'guava'))

Unzipping with zip + * (Reverse Zip)

pairs = [('a', 1), ('b', 2), ('c', 3)]
letters, numbers = zip(*pairs)
print(letters)
print(numbers)
('a', 'b', 'c')
(1, 2, 3)
